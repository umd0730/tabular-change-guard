# Tabular Change Guard

AIやスクリプトでCSVを整理した後、依頼していない変更を検出します。
Python 3.10以上で動き、実行時の追加ライブラリやAPI料金は不要です。
MITライセンスで利用・改変・再配布できます。

たとえば部署名の空白除去を頼んだのに、IDの `001` が `1` に変わったり、
行が消えたりする場合があります。このツールは元ファイルと変更後をキーで照合し、
変更を許可した列以外の値が保たれているかを調べます。

## サンプルを動かす

リポジトリのルートで実行します。

```sh
python -m tabular_change_guard examples/before.csv examples/after-good.csv --key id --allow team --sum quantity --format text
```

結果は `PASS`、終了コードは `0` です。`team` の修正と行の並べ替えを許可し、
ID・数量・備考の値と数量合計が変わっていないことを確認します。

`after-good.csv` を `after-bad.csv` に変えると `FAIL` になります。
ID変更、行の欠落、数量変更、数式に見える文字列を検出します。

## 判定する内容

| 指定 | 判定 |
| --- | --- |
| `--key id` | 照合キー。複数指定で複合キーになります。重複・空欄は入力エラーです。 |
| `--allow team` | 変更できる列。指定しなかった列の値は完全一致が必要です。 |
| `--required team` | 変更後に空欄がないか調べます。 |
| `--decimal quantity` | 数量が通常の十進数表記か調べます。指数・NaN・前後の空白は認めません。 |
| `--sum quantity` | 元と変更後の数量合計を、浮動小数点の丸めなしで比較します。 |
| `--before-encoding cp932` | Windows由来の日本語CSVを明示的に指定します。 |
| `--delimiter tab` | TSVを扱います。 |

既定の出力はJSONです。終了コード `1` は検出あり、`2` は入力・設定エラーです。
どちらも処理を止める対象にします。入力ファイルを上書きせず、通信もしません。
JSONには値やファイルパスを含めませんが、列名・行位置・ハッシュは含まれます。

## 利用できる範囲

対応はCSVとTSVです。XLSX、曖昧なIDの自動照合、値の自動修正は対象外です。
既定の入力上限は1ファイル10 MiB。検出結果は全件を集計し、詳細は最大1,000件です。
数式らしい文字列の検出は補助機能であり、表計算ソフトでの安全を保証しません。
`--allow` で指定した列は、追加条件を付けない限り自由に変更できます。

実行例はすべて架空データです。AI支援で作成した初期版であり、外部利用実績や
OSS支援制度への採択実績はまだありません。詳細は[英語版](README.md)を参照してください。
